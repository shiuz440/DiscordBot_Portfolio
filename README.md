#  Local-LLM Lecture Transcriber Bot

大学の講義録音データを完全ローカル環境でセキュアに文字起こしし、要約を自動生成するDiscordボットです。

##  プロジェクトの目的と背景
大学の講義という**「機密性の高いデータ（他者の著作物や個人情報が含まれる可能性のある音声）」**を扱うにあたり、OpenAIなどの外部APIへデータを送信することにはセキュリティ上の懸念がありました。
そこで、すべての処理（音声認識・文章校正・要約）を自前のローカルサーバー内で完結させることで、情報漏洩リスクをゼロに抑えつつ、学習効率を向上させるシステムを構築しました。

##  主な機能と技術的な工夫

1. **セキュアなローカル処理アーキテクチャ**
   - 音声認識には `faster-whisper`、言語モデルには `Ollama (Command-R)` を採用し、完全オフライン・ローカル環境での推論を実現しています。
2. **LLMによる音声認識エラーの自動校正**
   - Whisper特有の「専門用語の聞き間違い」や「同音異義語の誤変換」という課題に対し、要約処理の前に**LLM（温度パラメータ 0.1）を用いた校正フェーズ**を挟むパイプラインを構築しました。これにより、後続の要約精度を大幅に向上させています。
3. **堅牢なアクセス制御**
   - 不特定多数の利用を防ぐため、DiscordのユーザーIDベースでのホワイトリスト方式（ハードコードによる完全ブロック）を実装し、認可されたユーザーのみがシステムを利用できるよう設計しています。

##  システム構成・使用技術

- **言語**: Python 3.x
- **インターフェース**: Discord API (`discord.py`)
- **音声認識**: `faster-whisper` (large-v3 model)
- **自然言語処理**: Ollama (`Command-R` model)
- **インフラ**: ローカルAIサーバー (GPU推論)

### 処理フロー
1. ユーザーがDiscordに音声ファイル（mp3/m4a等）をアップロード
2. Botがローカルサーバー内のアーカイブディレクトリにファイルを保存
3. `faster-whisper` が音声をテキスト化（生データ）
4. `Ollama` が生データの誤認識・専門用語を文脈に合わせて校正
5. `Ollama` が校正済みテキストから事実ベースの要約を生成
6. Discordへ文字起こしテキストファイルと要約結果を返信
